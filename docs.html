Configuration

CLI commands

Send commands from the portal console over direct USB or through an authenticated Companion connection. A serial terminal can also be used at 115200 baud. Sensor labels are limited to 15 characters without spaces.

Start here

Run ver to test the connection, help for the upstream MeshCore command list, then set a unique node name and administrator password.

Keep keys private

The Victron and channel keys are saved on the node. The list and info commands redact them, but a terminal or browser console may retain the command itself.

MeshCore telemetry

Cayenne LPP channels

Telemetry is returned in encrypted peer responses to a Companion. A numeric Cayenne LPP channel can contain several values when their LPP data types differ—for example voltage, current and power can all use the same channel.

Slot calculation: the first configured device normally occupies slot 0. Victron uses 20 + slot × 8, Ruuvi uses 60 + slot × 2, and Shelly uses 70 + slot × 2. Removing a device can leave a free slot; use the relevant list command to see the actual slot.

Human-readable updates

Private status channel

This is separate from Cayenne LPP telemetry. It sends encrypted, readable group text to a configured MeshCore channel. Every receiver that should read it needs the same channel name and key.
